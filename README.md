# JavaScript Study 📚

2026년 10월 12일부터 시작한 **JavaScript 기초 학습 및 실습 기록**입니다.

JavaScript의 기본 문법부터 객체, 배열, 함수, 이벤트, DOM 조작까지 학습하며, HTML과 CSS로 작성한 웹페이지에 동적인 기능을 구현하는 방법을 익혔습니다.

단순히 문법을 암기하는 것이 아니라 **각 개념의 동작 원리를 이해하고 직접 코드로 구현하는 것**을 목표로 학습했습니다.

## 📅 학습 기간

**2026.10.12 ~ 2026.10.20**

## 🛠 사용 기술

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Visual Studio Code

## 📖 학습 내용

### 01. 변수 (Variables)

데이터를 저장하고 활용하는 JavaScript의 기본 문법을 학습했습니다.

**주요 학습 내용**
- `let`, `const`, `var`의 차이
- 변수 선언과 값 할당
- 문자열, 숫자, 불리언 등 데이터 타입
- 문자열 연결과 템플릿 리터럴
- 표현식과 문장

### 02. 연산자와 조건문 (Operators & Conditionals)

연산자를 이용해 데이터를 처리하고, 조건에 따라 실행 흐름을 제어하는 방법을 학습했습니다.

**주요 학습 내용**
- 산술 연산자
- 비교 연산자
- 논리 연산자
- 대입 연산자
- `if`, `else if`, `else`
- `switch` 조건문
- 조건에 따른 코드 실행

### 03. 객체와 forEach() (Objects & Array Iteration)

여러 데이터를 구조화하고 배열의 요소를 순회하는 방법을 학습했습니다.

**주요 학습 내용**
- 객체(Object)의 구조와 속성(Property)
- 객체의 속성 접근
- 배열(Array)과 인덱스(Index)
- `forEach()`를 이용한 배열 순회
- 콜백 함수(Callback Function)
- 배열 데이터를 활용한 HTML 요소 출력

### 04. 함수 (Functions)

반복되는 코드를 재사용 가능한 형태로 작성하고 실행하는 방법을 학습했습니다.

**주요 학습 내용**
- 함수 선언과 호출
- 함수 표현식
- 화살표 함수
- 매개변수(Parameter)와 인수(Argument)
- 반환값(`return`)
- 콜백 함수
- 함수와 이벤트의 연결

### 05. 클래스와 이벤트 (Class & Events)

HTML 요소의 CSS 클래스를 제어하고, 사용자 동작에 반응하는 기능을 구현했습니다.

**주요 학습 내용**
- `classList.add()`
- `classList.remove()`
- `classList.toggle()`
- `classList.contains()`
- `addEventListener()`
- `click`, `input`, `change`, `submit`
- `mouseover`, `mouseout`
- `keydown`, `keyup`
- `load`, `resize`
- 이벤트 객체(Event Object)
- 이벤트 버블링과 이벤트 위임

**주요 실습**
- 버튼 클릭에 따른 스타일 변경
- 메뉴 열기 및 닫기
- 체크박스를 활용한 완료 상태 변경
- 키보드 입력에 따른 요소 스타일 변경

### 06. DOM (Document Object Model)

JavaScript로 HTML 요소를 선택하고, 생성하거나 수정하여 웹페이지를 동적으로 변경하는 방법을 학습했습니다.

**주요 학습 내용**
- DOM의 개념과 구조
- `document.querySelector()`
- `document.querySelectorAll()`
- `getElementById()`
- `innerText`, `innerHTML`
- `createElement()`
- `createTextNode()`
- `appendChild()`
- `getAttribute()`
- `setAttribute()`
- `style`을 이용한 스타일 변경
- 이벤트 객체의 `target`

**주요 실습**
- JavaScript를 이용한 HTML 요소 생성
- 현재 날짜 및 시간 출력
- 링크 및 이미지 속성 변경
- 모달 창 열기 및 닫기
- 메뉴 클릭 이벤트 처리
- 썸네일 클릭 시 메인 이미지 변경
