# JavaScript Study 📚

2026년 10월 12일부터 시작한 **JavaScript 기초 학습 및 실습 기록**입니다.

JavaScript의 기본 문법부터 객체, 배열, 함수, 이벤트, DOM 조작, 배열 메서드를 활용한 데이터 가공까지 학습하며, HTML과 CSS로 작성한 웹페이지에 동적인 기능을 구현하는 방법을 익혔습니다.

단순히 문법을 암기하는 것이 아니라 **각 개념의 동작 원리를 이해하고 직접 코드로 구현하는 것**을 목표로 학습했습니다.

**2026.10.12 ~ 2026.10.21 (진행 중)**

## 🛠 사용 기술

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Visual Studio Code

## 📖 학습 내용

### 01. 변수 (Variables)

데이터를 저장하고 활용하는 JavaScript의 기본 문법을 학습했습니다.

**주요 학습 내용**
- `let`, `const`, `var`의 차이
- 변수 선언과 값 할당
- 문자열, 숫자, 불리언 등 데이터 타입
- 문자열 연결과 템플릿 리터럴
- 표현식과 문장

### 02. 연산자와 조건문 (Operators & Conditionals)

연산자를 이용해 데이터를 처리하고, 조건에 따라 실행 흐름을 제어하는 방법을 학습했습니다.

**주요 학습 내용**
- 산술 연산자
- 비교 연산자
- 논리 연산자
- 대입 연산자
- `if`, `else if`, `else`
- `switch` 조건문
- 조건에 따른 코드 실행

### 03. 객체와 forEach() (Objects & Array Iteration)

여러 데이터를 구조화하고 배열의 요소를 순회하는 방법을 학습했습니다.

**주요 학습 내용**
- 객체(Object)의 구조와 속성(Property)
- 객체의 속성 접근
- 배열(Array)과 인덱스(Index)
- `forEach()`를 이용한 배열 순회
- 콜백 함수(Callback Function)
- 배열 데이터를 활용한 HTML 요소 출력

### 04. 함수 (Functions)

반복되는 코드를 재사용 가능한 형태로 작성하고 실행하는 방법을 학습했습니다.

**주요 학습 내용**
- 함수 선언과 호출
- 함수 표현식
- 화살표 함수
- 매개변수(Parameter)와 인수(Argument)
- 반환값(`return`)
- 콜백 함수
- 함수와 이벤트의 연결

### 05. 클래스와 이벤트 (Class & Events)

HTML 요소의 CSS 클래스를 제어하고, 사용자 동작에 반응하는 기능을 구현했습니다.

**주요 학습 내용**
- `classList.add()`
- `classList.remove()`
- `classList.toggle()`
- `classList.contains()`
- `addEventListener()`
- `click`, `input`, `change`, `submit`
- `mouseover`, `mouseout`
- `keydown`, `keyup`
- `load`, `resize`
- 이벤트 객체(Event Object)
- 이벤트 버블링과 이벤트 위임

**주요 실습**
- 버튼 클릭에 따른 스타일 변경
- 메뉴 열기 및 닫기
- 체크박스를 활용한 완료 상태 변경
- 키보드 입력에 따른 요소 스타일 변경

### 06. DOM (Document Object Model)

JavaScript로 HTML 요소를 선택하고, 생성하거나 수정하여 웹페이지를 동적으로 변경하는 방법을 학습했습니다.

**주요 학습 내용**
- DOM의 개념과 구조
- `document.querySelector()`
- `document.querySelectorAll()`
- `getElementById()`
- `innerText`, `innerHTML`
- `createElement()`
- `createTextNode()`
- `appendChild()`
- `getAttribute()`
- `setAttribute()`
- `style`을 이용한 스타일 변경
- 이벤트 객체의 `target`

**주요 실습**
- JavaScript를 이용한 HTML 요소 생성
- 현재 날짜 및 시간 출력
- 링크 및 이미지 속성 변경
- 모달 창 열기 및 닫기
- 메뉴 클릭 이벤트 처리
- 썸네일 클릭 시 메인 이미지 변경

### 07. 배열 메서드와 데이터 가공 (Array Methods)

`map()`과 `filter()`를 학습하고, 기존에 배운 `forEach()`와 비교하여 배열 데이터를 목적에 맞게 처리하는 방법을 익혔습니다.

**주요 학습 내용**
- `map()`을 이용한 배열 요소 변환
- `filter()`를 이용한 조건별 요소 추출
- `forEach()`, `map()`, `filter()`의 차이
- 화살표 함수의 명시적 반환과 암묵적 반환
- 콜백 함수의 매개변수와 인덱스
- 원본 배열과 새로운 배열의 차이
- 전개 구문(`...`)을 이용한 객체 속성 복사 및 변경

**주요 실습**
- 배열의 모든 숫자에 특정 값 더하기
- 배열 요소를 두 배로 변환하기
- 합격 점수 이상인 데이터 추출하기
- 특정 가격 이하의 데이터 필터링하기

### 08. 배열 메서드를 활용한 상품 관리 및 검색 (Product Management & Search)

배열과 객체로 구성된 상품 데이터를 활용하여 전체 상품 출력, 할인 가격 계산, 가격 필터링, 실시간 검색 기능을 구현했습니다.

**주요 학습 내용**
- `forEach()`를 활용한 상품 목록 출력
- `map()`을 활용한 상품 가격 20% 할인
- `filter()`를 활용한 50,000원 이하 상품 추출
- `includes()`를 활용한 문자열 포함 여부 검사
- `input` 이벤트를 활용한 실시간 검색
- `innerHTML`을 이용한 동적 상품 목록 생성
- `toLocaleString()`을 이용한 가격 표시
- `length`를 이용한 상품 개수 출력
- 공통 렌더링 함수를 통한 코드 재사용

**주요 실습**
- 전체 상품 목록 출력
- 할인 가격 보기 버튼
- 5만원 이하 상품 필터링 버튼
- 상품 개수 표시
- 검색어에 따라 상품 목록이 변경되는 실시간 검색 기능

### 09. DOM과 이벤트를 활용한 탭 메뉴 (Tab Menu Interaction)

여러 탭 버튼과 콘텐츠를 연결하고, 클릭한 탭에 따라 활성화 상태와 표시 내용을 변경하는 기능을 구현했습니다.

**주요 학습 내용**
- `querySelectorAll()`로 여러 DOM 요소 선택
- `NodeList`와 인덱스의 활용
- `forEach()`로 각 버튼에 클릭 이벤트 등록
- `classList.add()`와 `classList.remove()`를 이용한 상태 변경
- `index`를 이용한 버튼과 콘텐츠 연결
- CSS의 `display: none`, `display: block`을 이용한 표시 제어
- JavaScript에서 초기 활성화 상태 설정

**주요 실습**
- 탭 버튼 클릭 시 활성화 스타일 변경
- 기존 활성화 상태 초기화
- 선택한 탭에 해당하는 콘텐츠 표시
- 페이지 초기 실행 시 첫 번째 탭 활성화
