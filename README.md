# JavaScript Study 📚

2026년 10월 12일부터 시작한 **JavaScript 기초 학습 및 실습 기록**입니다.

JavaScript의 기본 문법부터 객체, 배열, 함수, 이벤트, DOM 조작, 배열 메서드를 활용한 데이터 가공, 반복문과 스크롤 이벤트까지 학습하며, HTML과 CSS로 작성한 웹페이지에 동적인 기능을 구현하는 방법을 익혔습니다.

단순히 문법을 암기하는 것이 아니라 **각 개념의 동작 원리를 이해하고 직접 코드로 구현하는 것**을 목표로 학습했습니다.

## 📖 학습 내용

### 03. 객체와 forEach() (Objects & Array Iteration)

여러 데이터를 구조화하고 배열의 요소를 순회하는 방법을 학습했습니다.

**주요 학습 내용**

### 04. 함수 (Functions)

**주요 실습**

- `transform`을 `transition`으로 수정 완료
- 실제 브라우저에서 스크롤 활성화 및 애니메이션 동작은 별도 확인 필요
